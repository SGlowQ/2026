# 祈愿与倒计时 · WinUI 3 桌面版

把原来的网页版改写成 **Windows 原生 WinUI 3 桌面程序**，界面参照 Windows「设置」：左侧导航、云母材质（Mica）、圆角卡片、Fluent 控件。

**已上架 Microsoft Store：** https://apps.microsoft.com/detail/9PF3KCM4KN1B

## 最新版本

**2.0.6.0**

## 功能

| 页面 | 内容 |
| --- | --- |
| 倒计时 | 天 / 时 / 分 / 秒 / 毫秒实时倒计时；目标自动跟随下一个春节（带干支年份），也可保存多个自定义目标；一言每分钟刷新，带打字机特效与缓慢流动的彩虹渐变 |
| 祈愿 | 本期五星 UP + 四星 UP（竖线分隔），单抽与十连两个按钮，结果卡片显示在按钮右侧，五星/四星双保底进度条，最近中奖显示 10 条并按宽度自动换行 |
| 历史记录 | 当周记录，每 5 条一页，支持页码跳转，统计数据按星级分组，一键导出 Excel |
| 名单 | 粘贴或导入 TXT（至少 10 个名字），角色池自动分配（五星 : 四星 : 三星 ≈ 1 : 8 : 53），可重新洗牌 |
| 关于 | 版本信息、数据位置、偏好设置（一言 / 网络时间两个独立开关）、更改数据保存位置、分类清除数据、可折叠说明 |

### 元素图标

水 💧 · 火 🔥 · 雷 ⚡ · 草 🍀 · 冰 ❄ · 岩 🪨 · 风 🌀

### 抽卡规则

- 五星 0.6%，第 74 抽起逐步提升，第 90 抽必出
- 四星 5.1%，10 抽必出
- 三星 94.3%
- 出五星或四星时，50% 概率为当期 UP；未中 UP 则下次必中
- 五星 UP 与非 UP 交替累计 3 次后触发「捕获明光」
- 记录与保底状态按 ISO 周隔离，每周一 00:00 自动开始新的一周
- 抽卡记录永久保存，不会自动清理，可在关于页手动清除

## 数据保存在哪

默认位置：

```
%AppData%\WishLamp\WishCountdown\
├── settings.json   ← 名单、倒计时目标、一言/网络时间开关、自定义数据目录
└── history.json    ← 按周保存的抽卡记录与保底状态
```

全部保存在本机，不上传任何服务器。可以在「关于」页点「打开文件夹」直接查看。

### 更改保存位置

「关于」页 → 「数据保存位置」→ **更改位置**，选一个新文件夹即可。
现有数据会复制到新位置的 `WishCountdownData` 子目录，原位置保留不删。改完立即生效，重启后也会保留。

### 清除数据

「关于」页 → 「清除数据」卡片，可以分别清除：

| 项目 | 影响 |
| --- | --- |
| 抽卡记录 | 删除全部周的记录 + 保底进度 + 捕获明光状态 |
| 名单 | 删除全部名字，角色池会重置 |
| 倒计时目标 | 删除自定义目标，恢复跟随春节 |

每一项都会弹出确认框，写明影响范围和「此操作无法撤销」。

### 出错时

如果设置保存失败，会在 `%AppData%\WishLamp-save-error.log` 记录原因。
