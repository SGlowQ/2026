# 倒计时 × 祈愿点名

这是一个结合高考倒计时、班级励志展示和祈愿抽卡玩法的定制网页，支持自定义名单、随机 UP、捕获明光状态、历史记录和导出表格等功能。

## ✨ 项目特色

- ⏰ 标准倒计时：实时显示距离目标日期的天/时/分/秒/毫秒
- 🎲 祈愿抽卡：模拟原神式单抽与十连抽逻辑
- 🧩 自定义名单：支持在线编辑、导入 TXT、一人一行输入
- 🧠 捕获明光：新增五星彩UP触发状态，增加更强的抽卡规则体验
- 📊 历史记录：按周保存祈愿记录，可分页查看
- 📤 导出 Excel：可一键导出当周祈愿记录
- 🎵 音效系统：三星、四星、五星分别有专属音效
- 🎭 全屏特效：抽中角色时会触发全屏展示效果
- 💾 本地存储：记住保底、历史、名单设置等状态

## 🎮 功能说明

### 1. 倒计时功能

- 目标日期：默认值为 2026 年 06 月 07 日 00:00:00
- 显示格式：天、时、分、秒、毫秒
- 更新方式：按毫秒实时刷新

### 2. 祈愿机制

#### 概率分布
- 五星：0.6%
- 四星：5.1%
- 三星：94.3%

#### 保底机制
- 五星保底：连续 89 次未出五星时，第 90 次必出五星
- 四星保底：连续 9 次未出四星时，第 10 次必出四星
- 五星 UP：当获得五星时，有 50% 概率为当期 UP 角色
- 四星 UP：当获得四星时，有 50% 概率为当期 UP 角色之一

#### 捕获明光
- 在连续两次五星 UP 后，若前一发五星为非 UP，则会触发“捕获明光”状态
- 触发后，下一次五星会强制命中当期 UP 角色
- 状态会在命中后清空，并记录到抽卡状态面板中

### 3. 自定义名单

- 支持在线编辑名单
- 支持 TXT 导入（每行一个名字）
- 支持恢复默认名单
- 应用后会自动刷新页面以使修改立即生效

### 4. 历史记录与导出

- 记录当周祈愿结果
- 支持分页查看
- 支持导出为 Excel 文件
- 历史记录会自动去除 HTML 标签，仅保留纯文本名字

## 🎯 使用方式

1. 页面加载后自动开始倒计时
2. 点击 “祈愿” 按钮进行单抽
3. 长按 “祈愿” 按钮 0.5 秒可触发十连抽
4. 点击历史记录查看当周记录
5. 点击编辑按钮可自定义列表、导入 TXT 或恢复默认名单
6. 点击导出按钮可导出当前祈愿记录为 Excel
