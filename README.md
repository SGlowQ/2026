# 倒计时 × 祈愿点名

这是一个结合目标日期倒计时、班级励志展示和祈愿抽卡玩法的定制网页。页面支持自定义名单、固定星级角色池、随机 UP、保底状态、捕获明光、背景壁纸、历史记录和 Excel 导出。

## ✨ 项目特色

- ⏰ 标准倒计时：实时显示距离目标日期的天/时/分/秒/毫秒
- 🎲 祈愿抽卡：模拟原神式单抽与十连抽逻辑
- 🧩 自定义名单：支持在线编辑、导入 TXT、一人一行输入
- ⭐ 固定角色池：按总人数和现有星级概率分配名单，支持在“角色池”中查看
- 🧠 捕获明光：新增五星彩UP触发状态，增加更强的抽卡规则体验
- 📊 历史记录：按周保存祈愿记录，可分页查看
- 📤 导出 Excel：可一键导出当周祈愿记录
- 🎵 音效系统：三星、四星、五星分别有专属音效
- 🖼️ 壁纸背景：使用壁纸 API 自动加载背景
- 🎭 全屏特效：抽中角色时会触发全屏展示效果
- 💾 本地存储：记住保底、历史、名单设置等状态

## 🎮 功能说明

### 1. 倒计时功能

- 目标日期：默认值为 2026 年 06 月 07 日 00:00:00
- 显示格式：天、时、分、秒、毫秒
- 更新方式：按毫秒实时刷新

使用“修改倒计时”可以重新设置目标日期和时间。目标时间保存在当前浏览器中；网络时间服务不可用时，页面会自动使用本地时间作为备用。

### 2. 页面背景与常用控制

- 页面加载时自动通过壁纸 API 获取背景图片，并按屏幕大小铺满显示。
- 点击全屏按钮可以进入或退出浏览器全屏模式，适合课堂展示或大屏使用。
- 移动设备竖屏使用时会出现横屏提示，旋转设备后提示自动消失。
- 页面右侧二维码支持下载图片，方便保存或分享页面入口。

### 3. 一言励志语句

- 页面会从 hitokoto.cn 获取励志语句和出处。
- 通常每 60 秒更新一次；文字区域不可见时会暂停请求，重新可见后恢复。
- 网络请求失败时不会清空当前内容。

### 4. 祈愿机制

#### 概率分布
- 五星：0.6%
- 四星：5.1%
- 三星：94.3%

#### 保底机制
- 五星保底：连续 89 次未出五星时，第 90 次必出五星
- 四星保底：连续 9 次未出四星时，第 10 次必出四星
- 五星 UP：当获得五星时，有 50% 概率为当期 UP 角色
- 四星 UP：当获得四星时，有 50% 概率为当期 UP 角色之一

#### 捕获明光
- 在连续两次五星 UP 后，若前一发五星为非 UP，则会触发“捕获明光”状态
- 触发后，下一次五星会强制命中当期 UP 角色
- 状态会在命中后清空，并记录到抽卡状态面板中

### 5. 自定义名单与角色池

- 支持在线编辑名单
- 支持 TXT 导入（每行一个名字）
- 支持恢复默认名单
- 应用后会自动刷新页面以使修改立即生效
- 抽卡概率仍为五星 0.6%、四星 5.1%、三星 94.3%；角色池人数采用独立的近似比例，抽卡概率、保底和 UP 逻辑保持不变
- 角色池人数按五星:四星:三星约为 1:8:53 分配，五星至少 1 人、四星至少 3 人，三星可以没有
- 名单设置中的“角色池”按钮可以查看所有角色及其星级
- 名单输入格式为一行一个名字，空白行会自动忽略。
- 在线编辑后点击“应用名单”；也可以导入一人一行的 TXT 文件。
- 自定义名单至少需要 10 个非空名字，不足时不会保存。
- 角色池中的 UP 角色会排列在对应星级分组的最前面，并使用对应颜色标记。
- 点击“清空为模板”会删除自定义名单，恢复默认名单。

### 6. 名字滚动展示

- 点击“展开展示栏”查看当前名单，再次点击可以收起。
- 每个名字卡片显示姓名、星级文字和对应颜色。
- 名单会横向循环滚动，页面刷新后会重新排列展示顺序。
- 抽卡后，中奖名字会在滚动区域中显示对应星级的高亮效果。

### 7. 状态面板

- 点击“状态”按钮可以展开或收起当前抽卡状态。
- 面板显示累计抽卡次数、五星保底计数和四星保底计数。
- 同时显示五星 UP 保底、四星 UP 保底和捕获明光的激活状态。
- 状态按周保存在当前浏览器中，不同周的抽卡次数和保底计数相互独立。

### 8. 历史记录与导出

- 记录当周祈愿结果
- 支持分页查看
- 支持导出为 Excel 文件
- 历史记录会自动去除 HTML 标签，仅保留纯文本名字
- 每 5 条记录显示为一页，可以使用上一页、下一页或页码跳转。
- 记录中会显示姓名、星级、UP 状态、捕获明光、日期和时间。
- 点击导出按钮可以将当前周记录导出为 Excel 文件。

### 9. 音效与抽卡动画

- 三星、四星和五星分别使用对应音效。
- 抽卡结果会显示全屏星级动画，关闭动画后可以继续操作。
- 捕获明光动画期间会暂时锁定关闭按钮，动画结束后恢复操作。

## 🎯 使用教程

1. 打开页面，等待倒计时、背景壁纸和励志语句完成初始化。
2. 如需修改名单，点击编辑按钮，选择在线编辑或导入 TXT，确认至少有 10 个名字后应用。
3. 点击“角色池”查看当前名单的星级分配和 UP 角色顺序。
4. 点击“祈愿”进行单抽；按住约 0.5 秒后松开可进行十连抽。
5. 点击“状态”查看累计次数、五星保底、四星保底和捕获明光状态。
6. 点击历史记录按钮查看本周结果，使用分页控件浏览详细记录。
7. 点击导出按钮，将当前周的记录保存为 Excel 文件。
8. 点击简介按钮查看完整功能说明和规则说明。
